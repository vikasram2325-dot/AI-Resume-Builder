# 📄 AI Resume Builder

## About the Project
AI Resume Builder is an intelligent application that helps users create professional resumes based on their skills, education, and experience.

## Features
- Personal Information Entry
- AI Resume Generation
- Multiple Resume Templates
- Skill Suggestions
- PDF Resume Download

## Technologies Used
- Python
- HTML, CSS, JavaScript
- Google Gemini API

## Future Enhancements
- ATS Score Checker
- Cover Letter Generator
- Job Recommendation System

## Conclusion
AI Resume Builder helps job seekers create professional resumes quickly and easily.
